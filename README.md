# Portfolio Website
A modern, responsive personal portfolio showcasing projects, skills, and contact information.  
Built with clean UI design principles and smooth UX interactions.

## Features
- Fully responsive layout  
- Project showcase with images  
- Smooth navigation and animations  
- Modern, minimal UI  
- About, Skills, Projects, and Contact sections
